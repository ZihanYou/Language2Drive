# Language2Drive 0.1.0

Evaluate a driving model through one trajectory adapter across **CARLA, RealSim, nuScenes, NAVSIM and WOD-E2E**. This release packages the SDK, all five native evaluation backends, adapter examples, guides and component licenses with a per-file SHA256 inventory.

[Paper](https://arxiv.org/abs/2610.16634) · [Project page](https://ZihanYou.github.io/Language2Drive/) · [Benchmark Assets](https://huggingface.co/datasets/Mike087/Language2Drive) · [Installation guide](https://github.com/ZihanYou/Language2Drive/blob/main/docs/INSTALLATION.md)

## Install the wheel

```sh
python -m pip install https://github.com/ZihanYou/Language2Drive/releases/download/v0.1.0/language2drive-0.1.0-py3-none-any.whl
language2drive init --workspace ./l2d-workspace
language2drive adapter-check --adapter ./l2d-workspace/examples/constant_velocity.py
language2drive setup --workspace ./l2d-workspace --tracks all --runtime --download
```

`setup` selects official or mirror package sources based on connectivity and provisions the requested CARLA, RealSim and open-loop environments. It reconstructs the installed wheel for those environments, so a separate source checkout is unnecessary. Select individual backends with `--tracks carla`, `--tracks realsim` or `--tracks openloop`.

GPU evaluation uses the host NVIDIA drivers, downloaded simulator runtimes and the benchmark's resource manifests. nuScenes and Waymo source data follow their upstream access requirements. See the installation guide for resource paths, simulator services and adapter configuration.

## Included

- One model adapter for all five trajectory contracts; selectable evaluation groups and native scoring.
- Environment and resource planning, resumable downloads and SHA256 verification.
- A complete evaluation campaign configuration and GPU campaign validator.
- A project page with 129 case videos, an interactive six-map CARLA atlas, metric explanations and a model submission builder.

The attached `.sha256` file checks the wheel download. The wheel's bundled manifest checks each extracted backend file. Website videos and model weights are distributed separately from the SDK.
