What reaches the model?

Observed cameras, public ego history, the active instruction and a trajectory output specification. Evaluator targets, arm identities, opposing instructions and semantic contracts stay outside the model request. CARLA standardized evaluation also withholds route identity and simulator seed.

Metric and leaderboard notes

Closed-loop SemISR / Sem-CFPS are relaxed semantic proxies; open-loop SemSISR / SemCFPS enforce exclusive semantic success. The manuscript NAVSIM table uses the historical scorer. New SDK evaluations use the corrected scorer and belong to a separate profile. L2D uses the native nonlinear aggregation and driving component, not a simple mean. CARLA PSM requires its additional diagnostic routes. Senna's high-level bridge is a diagnostic configuration and is excluded here.

Community submission instructions and evidence requirements are in the leaderboard guide. This page displays training-free manuscript baselines: checkpoints are not trained or fine-tuned on Language2Drive. The official model is a future release.

05 / EVALUATE YOUR MODEL

One adapter.
All five tracks.

Keep your model in its own environment. The SDK handles public requests, trajectory validation, native exports and track-specific scoring.

01

Install the SDK.

Use the checkout or release wheel today. Optional extras select open-loop, CARLA or RealSim dependencies. PyPI publication is pending.

02

Implement predict(request).

Return ego-frame XY waypoints on the requested time grid. Your factory creates independent state for each rollout.

03

Configure once. Evaluate together.

Generate one resource configuration. Launch CARLA, RealSim and Open-loop through one adapter; each backend saves native evidence and scores.
