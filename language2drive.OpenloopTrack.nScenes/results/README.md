# Paper Table 9 replay

`table9.csv` preserves full-precision canonical heldout values. `table9.md` displays two decimals on the 0–100 scale. Both files were generated by:

```sh
python scripts/reproduce_paper.py --check-paper --output-dir outputs/paper_replay
```

The replay computes scores from the separately downloaded prediction trajectories and frozen contracts. It also writes each model's per-condition, per-family, family-macro, response coverage, bootstrap intervals, four-wording supplement and per-PCU details. File hashes and the actual scorer identity are retained in the generated `provenance.json`.
