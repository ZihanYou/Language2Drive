# Data and model provenance

The WOD-E2E track was made using the Waymo Open Dataset. Dataset access and downstream use follow the [Waymo Dataset License Agreement for Non-Commercial Use](https://waymo.com/open/terms/). The project repository distributes tooling; each user obtains source data through Waymo's own access process.

@misc{waymo_open_dataset, title = {Waymo Open Dataset: An autonomous driving dataset}, website = {https://www.waymo.com/open}, year = {2019-2025}}

External model repositories and checkpoints are referenced in `docs/MODELS.md` and `THIRD_PARTY_NOTICES.md`; their code and weights are downloaded separately and retain their upstream terms.
